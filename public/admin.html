Admin & Setup

Connect WhatsApp, check email delivery, and print unit QR codes.

📱 WhatsApp Connection

First time: open this page on the server, then scan the QR with the dedicated SPEL WhatsApp number (WhatsApp → Linked Devices → Link a Device). You only scan once.

📇 Alert Recipients

People who should receive an alert for every incident. Add a WhatsApp number (0300… works too — 92 is added automatically) or an email.

✉️ Email (SMTP)

Configure email/SMTP here — no need to touch .env. (Add recipients above under "Alert Recipients".)

🔗 Unit QR Codes

Run npm run qr on the server to generate printable QR codes into public/qr/. Each QR opens the report form pre-set to that unit.
